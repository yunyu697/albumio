### 3.2 差异项（均有明确归属）

| 差异 | 原因 / 计划 |
| --- | --- |
| 侧栏「标签」段与「全部图片 / 最近导入 / 收藏」入口未做 | 标签依赖 M4 的 `tags` 表；本里程碑只交付目录树 + 快速访问（图片 / 下载） |
| 快速访问行不显示数量 | 设计稿的数量来自全库索引；当前只有目录级 readdir 计数，全库数量与「最近导入 / 收藏」一起放 M4 |
| 状态栏左段为「42 项 · 已选 0 · 11.1 GB」 | 与设计稿一致；§9 原先写的 `3 / 128 项` 已按设计稿更正为「总项数 + 已选」，避免同一个数字重复出现 |
| 根节点为逻辑盘 + 主目录（Windows 显示 `Windows (C:)` 等） | 目录优先浏览必须能跨盘；设计稿只画了单根示例，不构成约束 |
| mock 数据的桶是「今天 / 昨天 / 本月」，设计稿是「今天 / 昨天 / 本周 / 2025 年 10 月」 | mock 拍摄时间只覆盖最近一个月；跨年/跨月/跨周由 `timeline.test.ts` 覆盖，不靠截图断言 |
| 分组头 DOM 为绝对定位 + sticky 覆盖层 | 虚拟滚动只挂可视行，无法直接复用设计稿的静态 `sticky`；几何与配色逐值对齐 |

## 5. 已知限制与待办

1. **时间线取时延**：进目录时按 250 条一批串行读 `taken_at`（1 万项约 40 次 invoke），首屏分组要等日期读完才出现。M8 增量索引落地后改为查 `files.taken_at`，这条串行读取随之删除。
2. **时间线不缓存日期**：切换目录或刷新会重读；同上由 M8 索引解决。
3. **跨 3 年样本目录未做端到端截图**：分桶逻辑由单测覆盖（含跨年/跨月/跨周），端到端用 mock 目录；真实目录的端到端复验放到 M8 索引回填后。
4. **macOS / Linux 未实机**：`roots()` 的 unix 分支返回 `/` + `$HOME`，`disk()` 用 `statvfs`，均只有编译期保证；M9 装包时补测。
5. **时间线折叠不做**：按 §11.7 明确不提供折叠/展开（时间线是浏览视图，不是目录树）。
6. 标签分组、最近导入、收藏入口归 M4。
