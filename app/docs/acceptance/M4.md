## 2. 元数据口径（与规范逐条对应）

1. **EXIF 与 XMP 冲突时以 XMP 为准**：`merge()` 对标题、版权、评级、拍摄时间都先取 XMP，再回退 EXIF；关键词只来自 `dc:subject`（EXIF 无对应标准字段）。
2. **缺失拍摄时间不伪造**：EXIF `DateTimeOriginal` 与 XMP `xmp:CreateDate` 都没有时，`taken_at` 取 mtime，来源标 `inferred`，且 `taken_at_text` 返回 `null`；前端显示 mtime 的本地时间并加「（推断）」。状态栏同样标注。
3. **评级来源**：EXIF 没有标准 Rating 标签，评级只认 `xmp:Rating`，避免把厂商私有标签猜成“来源”。
4. **直方图口径**：用管线产出的 L1 代理统计（像素已在 Rust 侧转过 sRGB），裁切区域外仍计入；三通道各 12% 叠加渲染（§11.3）。
5. **XMP 只读头部 1MB**：JPEG APP1 / PNG iTXt / WebP XMP 都在文件头，不为元数据整读 40MB 原图。
6. **索引是旁路**：`index.db` 被删、损坏、不可写都不影响浏览/看图/编辑/导出；`albumio_meta` 写索引失败只打日志。

### 4.2 差异清单

| # | 差异 | 结论 |
| --- | --- | --- |
| 1 | 「地点」设计稿为示例城市（京都府京都市），实现为「—」 | **已知差距**：M4 未接反向地理编码；坐标来自 EXIF GPS 真实显示。接地理编码前不编造地点名 |
| 2 | 「颜色标签」设计稿为示例值（旅行），实现为「—」 | **已知差距**：M4 数据模型无颜色标签字段；等设计稿补字段定义再实现（G2） |
| 3 | 「评分」实机目录里的图没有 `xmp:Rating`，显示「—」；假数据样本显示五星 | 数据差异，非布局差异 |
| 4 | 直方图为 64 箱，设计稿是 34 根示意条 | 数据分辨率差异；总高、左右内边距、条间距与稿一致 |
| 5 | 「方向」行加了 EXIF 来源胶囊 | §11.3 要求标注方向来源；设计稿未画胶囊，按规范补 |
| 6 | ICC 描述名已抽取，但设计稿没有对应行 | **按 G2 暂不显示**；补设计稿加行后再上屏 |
| 7 | 「+ 添加」标签不可编辑 | 标签写入属于 M6 非破坏性编辑的 sidecar 流程，M4 只读 `dc:subject` |

## 5. 实机验证（1 万项目录，%TEMP%\albumio-10k）

1. 选中首张 `DSC_00001.JPG`（800×600，无 EXIF/XMP）：
   - 状态栏中段：`DSC_00001.JPG 800×600 JPEG 21.8 KB 2026-11-16 00:17（推断）`——回退 mtime 且明确标注「推断」；
   - 检查器：尺寸/格式/大小/直方图有值，拍摄时间带「推断」胶囊，XMP 字段为「—」。
2. 索引落盘：`%APPDATA%\albumio\index.db`（WAL，`albumio_index_status` 返回 `{"files":1,"schema":1,"bytes":201888}`）。
3. **folder-first**：关闭应用 → 删除 `index.db / -wal / -shm` → 重启 → 网格、选中、检查器全部照常，`index.db` 自动重建并在看图后重新写入 1 行。
4. 截图用 CDP `Emulation.setDeviceMetricsOverride` 压回 1440×900 / DPR=1（本机 DPR=2）。
5. 状态栏中段与检查器共用同一次 `albumio_meta` 结果（`onMeta` 回传），不存在两处显示不一致。
