## 2. 验收标准逐条证据

### 2.1 改完退出重进，编辑状态完整还原

- `albumio-core` 单测 `edits_survive_reopen_and_clear`：写入 → 关闭索引 → 重开 → 读回 JSON 与写入值逐字段相等；`edits_clear` 后读回为空。
- `edit.rs` 单测 `sidecar_roundtrip_and_stale`：sidecar 写盘 → 读回 `EditStack` 与原值相等；改动 source_mtime_ns 后 `is_stale` 为真。
- IPC 层：`albumio_edits_load` 对 sidecar 与索引取 `updatedAt` 较新者（平局取 sidecar），即「关掉应用再开」与「只丢索引」两种情形都能还原。
- 未覆盖：真实 GUI 下的手动「编辑 → 退出 → 重进」尚未跑，见 §5 第 1 条。

### 2.2 导出副本与预览在像素级一致

`pipeline.rs` 集成测试 `edit_preview_and_export_agree_without_touching_original`，同一组参数（曝光 +0.5、对比度 +0.2、饱和度 +0.3、裁剪 0.1/0.1/0.8/0.8）分别走预览与导出：

- 尺寸相等：预览与导出均为同一宽高（裁剪后的尺寸），导出返回值与解码后的 JPEG 尺寸一致。
- 平均像素差（RGB 三通道）：**3.86 / 255**，阈值 8（差异来自 WebP q80 与 JPEG q90 编码噪声）。
- 构图与曝光无偏差：平均差远小于阈值，不存在整幅位移或增益差。

### 2.3 原图字节不变

- 同一测试中 `before` 与导出两次后的 `fs::read` 结果 `assert_eq!` 相等：「原图字节必须一个不差」。
- 导出不覆盖：连续两次导出得到不同路径，第二次为 `_Albumio_1.jpg`。
- 目录内除 `.albumio/`（sidecar 与缓存）外无新增文件；导出只写 `原名_Albumio*.jpg`。

### 2.4 移除某步 → 停用且计数减一，其余步骤顺序不变

- `m6-check` 第 2–3 步：旋转 + 曝光 + 对比度 + 锐化后操作栈 5 行（含裁剪），计数文案「5 个操作」；点第 3 行移除 → 该行 `.off`（变暗 + 删除线），计数「4 个操作」；再点恢复 → 计数回到 5。
- 顺序：`edit.rs` 单测 `normalize_order_and_dedupe` 断言乱序输入被重排为 `["orient","crop","exposure","sharpen"]`，且重复 `exposure` 只保留后出现的一条。
- 停用语义：前端以 `disabled` 列表过滤 `toStack`，被停用的步骤不进入保存/导出的栈，但保留在操作栈里可恢复。

## 5. 差异项与已知限制

1. **真实 GUI 端到端未手动跑**：本轮验证为 Rust 测试 + headless 浏览器自检。Tauri 窗口内的「编辑 → 重进还原 → 导出落盘 → 原图哈希」需人工跑一遍（`certutil -hashfile` 比对），当前由 Rust 集成测试覆盖核心路径。
2. **导出不保留 EXIF**：只写像素，不含拍摄参数、方向标签（方向已烘进像素）。元数据保留策略按 M7「转换的元数据保留策略」统一处理。
3. **导出固定 JPEG q90**：M6 只做「导出副本」，格式/质量选项属于 M7 批量转换；冲突命名 `_1` 已生效。
4. **内嵌 XMP 回写未实现**：当前为「SQLite + sidecar」两层，第三层（写回文件内嵌 XMP）留待需要时补；sidecar 已带 stale 检测，原图被外部改动时可提示。
5. **预览延迟未测**：滑杆 60 ms 防抖是人为上限，未测端到端「拖动 → 新预览上屏」的 P95；需要在真实 Tauri 窗口 + 大图上压测。
6. **浏览器 mock 的预览是 CSS 滤镜近似**：因此像素级一致性证据只取 Rust 集成测试，浏览器截图只用于几何与交互验收。
7. **色彩模型为 sRGB 8 位**：曝光/对比度/饱和度在 sRGB 空间逐通道/按亮度处理，未做线性光与广色域；与既有预览/解码口径一致，色彩管理深化随 M7/M9。
