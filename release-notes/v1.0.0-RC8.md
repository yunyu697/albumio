# Albumio v1.0.0-RC8

第八个候选版本。在 RC7 基础上，本版聚焦 **Viewer 滚轮缩放无极调节**、**设置面板扩展**（排序/递归深度/重启目录/布局预设）、**面板可拖拽调宽 + 界面内折叠按钮**、**Inspector 预览升级到 L2 代理**、以及主题切换的 segmented control 紧凑化。

## 本版变更

### Viewer 滚轮缩放无极调节

- 根因：连续滚轮事件期间，每次 wheel 都触发 `photoStyle.transition: "transform 60ms cubic-bezier(...)"`，多条 transition 叠加导致跟手卡顿。
- 修复：`zoomingRef` + 150ms debounce timer。wheel 事件期间 `transition: "none"` → 跟手 100%；wheel 停 150ms 后恢复 `transform 60ms` → 平滑落定。
- 参数不变：`ZOOM_MIN = 0.02` / `ZOOM_MAX = 8` / 指数映射 `factor = Math.exp(-ev.deltaY * 0.0015)`。

### 设置面板扩展（从 3 项 → 11 项 + 布局预设）

- 新增偏好：`sort`（nameAsc/按排序菜单当前值）、`defaultRecursiveDepth`（0/2/4/6 层穿透）、`reopenLastDir`（启动自动打开上次目录）、`lastDir`（上次浏览的目录）。全部存 localStorage。
- 启动时如勾选 `reopenLastDir` 且有 `lastDir`，自动 `openDir(lastDir)`。
- Browse 组件新增 `maxDepth: number` prop，透传到后端 `albumio_list` 的 recursive 递归深度。

### 面板可拖拽调宽 + 界面内折叠按钮

- 侧栏和主内容之间、主内容和检查器之间各加一条 4px 宽 divider（hover 变 6px + accent-color 高亮 + col-resize 光标）。
- 侧栏 / 检查器折叠时，边界出现 `pane-toggle` 展开按钮（`«` / `»`）。
- 拖拽宽度存 localStorage：侧栏 140–400px / 检查器 200–500px，重开窗口还原。
- 折叠按钮和快捷键（Ctrl+B / Ctrl+I）并行工作。

### Inspector 预览升级

- 根因：预览用 `thumbUrl(path, "l1")`（约 256px 缩略图），和网格缩略图没差别。
- 修复：改用 `previewUrl(path)`（L2 2048px 代理），`object-fit: contain` + 4:3 aspect-ratio 自适应面板宽度。
- 正确调用 `releasePreview(path, url)` 释放代理。

### 主题切换 segmented control 紧凑化

- 根因：旧 `.sp-theme-btn` 每个按钮都无条件渲染 `<Icon id="i-check">`，导致三个按钮全部显示勾选图标。
- 修复：改成 segmented control（`.sp-seg` + `.sp-seg-item`），active 项有 `.active` 高亮块（`background: accent-weak; color: accent`）。无勾选图标，紧凑一行。

### 布局预设

- 设置面板新增「布局预设」section：4 种方案一键切换
  - **扩展**：侧栏开 + 检查器开（默认）
  - **专注**：侧栏关 + 检查器开
  - **浏览**：侧栏开 + 检查器关
  - **极简**：两侧全关，满屏浏览
- 每个方案有可视化缩略图（侧栏位 + 主区 + 检查器位），当前组合自动高亮。

## 各平台实际表现

### Windows

- 构建产物：`albumio_1.0.0-RC8_x64-setup.exe`、`albumio_1.0.0-RC8_x64_en-US.msi`、`albumio_1.0.0-RC8_x64.zip`（便携）。
- 安装包扩展名关联同 RC7（39 条）。

### macOS

- universal2 构建（arm64 + x86_64），`albumio_1.0.0-RC8_universal.dmg`、`albumio.app.tar.gz`。
- universal2 交叉编译耗时约 18 分钟（含 libde265 / libjpeg-turbo / libwebp 三库双架构构建）。

### Linux

- `albumio_1.0.0-RC8_amd64.AppImage`、`albumio_1.0.0-RC8_amd64.deb`。
- Rust 原生解码同 RC7（avif-rust / rawler / 内置 libheif）。

## 已知限制

- 未实现列表视图（Browse 目前只有网格/时间线），留到 RC9。
- universal2 交叉编译耗时偏长（~18 分钟），后续可考虑拆分架构分步或预编译缓存。
- 本版真机交互验证未做（滚轮缩放手感 / divider 拖拽流畅度需要本地跑 tauri dev 实测）。

## 校验方式

- 每个安装包附 `.sig`（minisign），可用应用内嵌公钥校验；`latest.json` 的 minisign `trusted comment` 应含 `file:albumio_*`。
- `SHA256SUMS` 覆盖全部附件（含 `.sig`）。
