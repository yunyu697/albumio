# Albumio v1.0.0-alpha1

第一个 alpha 版本：应用外壳可运行，图像管线打通（目录浏览与网格编辑仍在后续里程碑）。

## 本版包含

- **应用外壳**：标题栏 / 工具条 / 侧栏 / 主区 / 检查器 / 状态栏，六档宽度（1440 / 868 / 867 / 735 / 734 / 432）按设计稿回归通过，最小窗口 432×284。
- **图像管线（`albumio-core`）**：魔数探测格式、按目标尺寸解码、EXIF Orientation、lcms2 → sRGB、WebP 输出（L0 无损 32px / L1 256px / L2 2048px q80）。
- **缩略图缓存**：`xxh3_128` 键 + 两级目录分片、临时文件 fsync 后原子 rename、L1 2GB / L2 4GB 预算淘汰。
- **Tauri 命令**：`albumio_probe` 与 `albumio_thumb` 已接入管线。

## 已知限制

- HEIC / AVIF / RAW 尚未接入解码（探测可识别，调用会返回明确的 Unsupported）。
- 目录浏览、网格与编辑器尚未实现，本版主要用于验证外壳与出图链路。
- 安装包**未做代码签名与 Apple 公证**：Windows SmartScreen / macOS Gatekeeper 会提示"未知开发者"，需手动允许。
- Linux 自动更新只使用 AppImage；deb 为手动下载项。

## 校验方式

- 每个安装包都附 `.sig`（minisign），可用应用内嵌公钥校验；`latest.json` 含三平台更新条目。
- `SHA256SUMS` 覆盖全部附件（含 `.sig`），下载后可用 `sha256sum -c` 逐条核对。
