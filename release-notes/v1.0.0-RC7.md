# Albumio v1.0.0-RC7

第七个候选版本。除了 RC6 修掉的「打开即卡死」，本版按顺序叠加了 M1 解码（RAW 内嵌预览 + AVIF 纯 Rust）、M9 系统集成补齐（安装包 39 条扩展名关联）、显示名改为 `Albumio`，以及亮/暗主题切换 + 偏好持久化 + 设置面板入口。

## 本版变更

### 显示名与文件名解耦

- 用户可见的应用名统一为 `Albumio`：安装程序、开始菜单 / 桌面快捷方式、应用与功能列表、窗口标题、macOS 访达与 Dock、Linux 桌面菜单。
- **下载得到的文件名一个都没变**：仍是 `albumio_1.0.0-RC7_x64-setup.exe`、`albumio_1.0.0-RC7_x64_en-US.msi`、`albumio_1.0.0-RC7_universal.dmg`、`albumio_1.0.0-RC7_amd64.AppImage`、`albumio_1.0.0-RC7_amd64.deb`、`albumio.app.tar.gz`；`latest.json` 里的资产名与下载地址、`SHA256SUMS` 全部沿用原来的小写命名。
- 内部标识一个都没动：包标识 `com.albumio.app`、Rust crate 与 npm 包名、`albumio_*` 命令 / 事件名、数据目录 `%APPDATA%\albumio`。

Tauri 的 `productName` 同时决定系统显示名和产物文件名，没有独立的显示名字段。本版的处理是：
- `productName` 设为 `Albumio`，让系统各处显示大写；
- 显式 `mainBinaryName: "albumio"`，保住可执行文件名仍是 `albumio.exe`（便携构建脚本、开机自启路径、已有快捷方式目标都不受影响）；
- 发版流水线在展平产物后、签名前执行 `scripts/rename-artifacts.mjs`，把 `Albumio_*` 前缀改回 `albumio_*`，随后删预签 `.sig` 让 `signer sign` 按小写文件名重新签。

### 解码（M1）

- **RAW**：三平台统一用 `rawler` 抽相机内嵌预览（不做 demosaic），25 个扩展名（dng/cr2/cr3/crw/nef/nrw/arw/srf/sr2/raf/rw2/raw/orf/pef/rwl/srw/x3f/3fr/fff/iiq/mos/mrw/kdc/mef/erf）；前端标注 `RAW（仅预览）`，因为相机内嵌预览通常是半尺寸或更小的 JPEG，不是传感器原生分辨率。
- **AVIF**：三平台统一用 `avif-rust`（MIT 纯 Rust），不引 dav1d/libavif 的 nasm/cmake 原生构建，也不依赖 Windows「AV1 视频扩展」商店包。参考 ffmpeg(libaom) 解同一文件对比：真实照片 800×600 整帧 MAE 2.66、最大差 24、逐通道偏置 < 2，色彩矩阵与量程正确。已知取舍：不读 ICC，未应用 irot/imir，广色域 AVIF 按 sRGB 显示。
- Windows HEIC 继续走系统 WIC；macOS/Linux 继续走内置 libheif（静态编译）。

### 系统集成（M9）

- 安装包的扩展名关联表补齐：从 14 条扩到 **39 条**（原来只有传统栅格格式，现在加了 25 个 RAW 后缀）。本机用 Windows Installer COM 只读查询 MSI 的 Extension 表，39 条且 ProgId 均为 `Albumio.<ext>`。
- 此前已实现并过编译的：单实例（`tauri-plugin-single-instance`，第二进程把目标交给主窗口并置前）、剪贴板文件列表（Windows CF_HDROP / macOS osascript furl / Linux wl-paste→xclip）、拖放（整窗接收，走 `albumio_resolve_target` 统一解析）、默认打开方式（双击关联文件 → 进父目录并定位该文件）。

### 亮/暗主题与偏好持久化

- 设置面板：标题栏齿轮按钮点开 Popover，三项即时生效——外观（跟随系统 / 浅色 / 深色）、侧栏开关、检查器开关。关闭 Popover 即关闭，无"保存/取消"按钮。
- 主题：启动前 `hydrateTheme()` 就把 `<html data-theme>` 落下，避免首屏闪深色；`auto` 模式跟随 `prefers-color-scheme` 系统变化。偏好存 `localStorage`。`palette.css` 里浅色/深色两套色板早已写好，这次补了让它生效的 JS 闭环。
- 偏好持久化：`sidebarOpen`、`inspectorOpen`、`cellIdx`（网格尺寸）、`view`（目录/时间线）、窗口位置/尺寸/最大化——重开窗口全还原。窗口状态 Resized/Moved 事件 300ms 防抖写 localStorage。
- 标题栏工具栏 active 态补完：批量按钮打开时高亮；F5 刷新 / 批量处理启动各 Toast 反馈。

## 各平台实际表现

### Windows

- 安装程序标题、「应用和功能」里的条目、开始菜单与桌面快捷方式均为 `Albumio`。
- 安装目录为 `%LOCALAPPDATA%\Albumio`（默认每用户安装），可执行文件在 `%LOCALAPPDATA%\Albumio\albumio.exe`。
- MSI 的 ProductName 为 `Albumio`。WiX 的 UpgradeCode 默认由 `productName` 派生，本版没有固定它，因此 RC7 与本仓库此前的 Windows 版本会被系统视为两个独立应用。当前实际没有用户，按约定不做迁移兼容处理。
- 扩展名关联已含 39 个后缀（jpg/jpeg/jpe/png/webp/heic/heif/heics/heifs/tif/tiff/bmp/gif/avif + 25 个 RAW）。
- 下载到的安装包文件名不变：`albumio_1.0.0-RC7_x64-setup.exe`、`albumio_1.0.0-RC7_x64_en-US.msi`。

### macOS

- 应用包为 `Albumio.app`，访达、Dock、菜单栏显示 `Albumio`；`CFBundleIdentifier` 仍是 `com.albumio.app`。
- dmg 与更新包的文件名在发版时改写回小写：`albumio_1.0.0-RC7_universal.dmg`、`albumio.app.tar.gz`。

### Linux

- 桌面菜单条目显示 `Albumio`，安装后的可执行文件仍是 `albumio`（`/usr/bin/albumio`）。
- AppImage 与 deb 文件名不变：`albumio_1.0.0-RC7_amd64.AppImage`、`albumio_1.0.0-RC7_amd64.deb`。
- 自动更新仍然只走 AppImage；deb 为手动下载项。

## 已知限制

- 安装包**未做代码签名与 Apple 公证**：Windows SmartScreen 与 macOS Gatekeeper 会提示「未知开发者」。这是外部依赖（证书/公证凭据），不是代码缺陷。
- Win11 右键菜单：COM DLL + MSIX sparse 包代码已就绪（`app/windows-shell/`），但 MSIX 必须签名才能 `Add-AppxPackage` 注册；`AlbumioShell.dll` 尚未接入 MSI/NSIS 安装器。
- RAW 无真实样张端到端验证（抽预览到底覆盖哪些机型未知）；AVIF 不读 ICC、未应用 irot/imir（代码注释已写）。
- 三平台装包真机验证未做：双击关联、拖放、冷启动、卸载残留、G3 叠图都需要干净 VM 或真机。
- `com.albumio.app` identifier 末尾 `.app` 与 macOS bundle 扩展名冲突（Tauri 警告），签名前需确定是否改。

## 校验方式

- 每个安装包都附 `.sig`（minisign），可用应用内嵌公钥校验；`latest.json` 含三平台更新条目，其 minisign `trusted comment` 里的 `file:` 应与实际资产名一致（小写 `albumio_*`）。
- `SHA256SUMS` 覆盖全部附件（含 `.sig`），下载后可用 `sha256sum -c` 逐条核对。
