# Albumio v1.0.0-RC1

第一个候选版本：从目录浏览、网格、看图、编辑、批量到目录监听的完整闭环，加上三平台打包与系统集成。

## 本版包含

- **目录浏览与网格（M2–M4）**：readdir/stat 分离与 P0–P4 调度、虚拟滚动、五档格宽；侧栏目录树、时间线、检查器（EXIF/尺寸/色彩）与状态栏。
- **全屏看图（M5）**：L2 代理图、缩放平移、胶片条、信息浮层；Windows 上 HEIC/AVIF/RAW 走系统 WIC。
- **编辑器（M6）**：方向、裁剪、色彩、锐化，操作栈与撤销，sidecar 持久化与导出。
- **批量处理（M7）**：模板重命名、转换/缩放、冲突避让、失败原因、暂停/重试与取消清理。
- **目录监听与增量索引（M8）**：300 ms 去抖、批量上限 2000 条、改名配对、stat 校正、溢出降级，外部改动合并时不丢选中与滚动位置。
- **打包与系统集成（M9）**：
  - Windows 出 MSI 与 NSIS，8 组图片扩展名关联、长路径清单、portable zip；macOS 出 universal2（Intel + Apple Silicon）；Linux 出 AppImage/deb 并附 Flatpak 清单。
  - 自绘标题栏的拖拽区与最小化/最大化/关闭；启动参数与拖放打开（双击关联文件进父目录并定位）；管理员运行时明确提示拖放不可用。
  - **单实例**：再次打开关联文件时把参数转给已运行的窗口并置前。
  - **剪贴板粘贴**：`Ctrl/Cmd+V` 直接打开资源管理器/Finder 里复制的图片。
  - **HEIC**：macOS/Linux 内置 libheif（静态随包），Windows 继续用系统 WIC。
  - **Win11 右键菜单**：MSIX sparse + `IExplorerCommand` 工程与构建脚本已就绪（`npm run build:shell`），标识集中在 `app/windows-shell/identity.json`。
- **更新通道**：`latest.json` 覆盖 `windows-x86_64` / `darwin-aarch64` / `linux-x86_64`，全部附件带 minisign `.sig`。

## 已知限制

- 安装包**未做代码签名与 Apple 公证**：Windows SmartScreen 与 macOS Gatekeeper 会提示"未知开发者"，需手动允许；macOS 包也未公证。
- Win11 右键菜单需要签名后的 MSIX 才能 `Add-AppxPackage` 注册，本版安装包暂未携带 `AlbumioShell.dll`，菜单需等证书与安装器接线。
- AVIF / RAW 仍未接入解码，调用会返回明确的 Unsupported。
- 单实例、剪贴板、右键菜单与 macOS/Linux 的 HEIC 解码只过了编译与本地构建，尚未做真机交互验证。
- Linux 自动更新只使用 AppImage；deb 为手动下载项。

## 校验方式

- 每个安装包都附 `.sig`（minisign），可用应用内嵌公钥校验；`latest.json` 含三平台更新条目。
- `SHA256SUMS` 覆盖全部附件（含 `.sig`），下载后可用 `sha256sum -c` 逐条核对。
